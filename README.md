# Карточные войны: исходный код

Код фанатского порта настольной игры Card Wars из мультсериала «Время приключений». Игра сделана на Godot 4. Скачать готовую игру можно на странице [kiberbus/card-wars](https://github.com/kiberbus/card-wars).

Здесь лежит код игры: правила и карты, ИИ, интерфейс, Бесконечный поезд, клиент игры по сети и тесты. Картинок, музыки и звуков здесь нет. Они принадлежат авторам мультсериала и настольной игры, и выкладывать их мы не можем. Игра берёт их из установленной копии.

Обсуждение и вопросы в нашем [Discord](https://discord.gg/hDNwrYtvy).

## Как запустить

1. Скачай [Godot 4.7](https://godotengine.org/download), обычную версию без .NET.
2. Установи саму игру со страницы [kiberbus/card-wars](https://github.com/kiberbus/card-wars) и запусти её один раз, чтобы она скачала последнее обновление.
3. Открой в Godot файл `project.godot` из этой папки и запусти проект (F5).

Картинки и звуки проект ищет так:

- на Windows в папке установщика: `%LOCALAPPDATA%\Programs\CardWars\CardWars.pck`;
- на macOS в `CardWars.app` из папки «Программы»;
- если игра стоит в другом месте (zip-версия, Linux), создай рядом с `project.godot` файл `game_path.txt` и напиши в нём путь к `CardWars.pck` или к папке с ним.

Обновления, которые скачала установленная игра, проект тоже подхватывает. Если в коде появились новые карты, а игра ещё не обновлена, у таких карт не будет картинок.

## Тесты

Тесты запускаются без окна:

```
godot --headless --path . -s res://tests/rules_test.gd
godot --headless --path . -s res://tests/cards_test.gd
godot --headless --path . -s res://tests/deck_rules_test.gd
godot --headless --path . -s res://tests/hooks_test.gd
godot --headless --path . -s res://tests/sim.gd -- 300 1
```

Все должны проходить без ошибок. Если правишь правила или карты, добавь проверку в `tests/cards_test.gd`.

## Где что лежит

- `scripts/core`: правила, движок партии, карты и их способности, реплеи.
- `scripts/ai`: ИИ соперника.
- `scripts/train`: Бесконечный поезд.
- `scripts/ui`: экраны, стол, конструктор колод, раскладка для телефонов.
- `scripts/net`: игра по сети, аккаунты, обновления.
- `data/cards.json`: все карты. `data/ai_policy*.json`: веса ИИ.
- `rl_training`: обучение ИИ на Python.
- `tests`: тесты.

Сервера (комнаты по сети, рейтинг, турнирный бот) в этом репозитории нет. Игра из редактора подключается к тому же серверу, что и обычная.

## Как предложить правку

Сделай форк, внеси правку в отдельной ветке и открой pull request. Опиши, что поменялось и как это проверить. Интерфейс должен работать и на телефоне: проверь его в альбомной ориентации на маленьком экране.
